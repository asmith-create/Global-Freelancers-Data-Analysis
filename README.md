# Global Freelancers Data Analysis

## 📊 Project Overview

This project analyzes a dataset of global freelancers using Microsoft Excel. The goal was to explore freelancer demographics, skills, experience, ratings, hourly rates, languages, and other characteristics.

This was my first beginner-level data analytics project, where I practiced data cleaning, PivotTables, data analysis, and dashboard creation.

## 🛠️ Tools Used

* Microsoft Excel
* PivotTables
* Excel Charts
* Data Cleaning
* Data Analysis

## 📂 Dataset

The dataset contains approximately 1,000 freelancer records and includes information such as:

* Freelancer location
* Gender
* Age
* Years of experience
* Primary skill
* Hourly rate
* Languages spoken
* Rating
* Customer satisfaction
* Active status

## 🔎 Analysis Performed

I analyzed the data to explore:

* Average rating by primary skill
* Years of experience
* Hourly-rate distribution
* Most common languages
* Freelancer distribution by country
* Freelancer characteristics and performance

## 📊 Dashboard

The Excel dashboard contains visualizations for:

* Average Rating by Primary Skill
* Years of Experience
* Hourly Rate
* Freelancer Count by Language
* Freelancer Count by Country

## 💡 Skills Demonstrated

Through this project, I practiced:

* Data cleaning
* Data transformation
* PivotTables
* Data visualization
* Dashboard creation
* Basic data analysis
* Drawing insights from datasets
